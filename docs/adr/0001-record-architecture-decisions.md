# Record architecture decisions

Decisions that shape this repo (its scope, its format, how it is checked) are recorded as short Markdown files in `docs/adr/`, numbered in order, so a future contributor can see why the repo is the way it is instead of guessing.

Vocabulary lives in `GLOSSARY.md`. Only record a decision when it is hard to reverse, surprising without context, and the result of a real trade-off.
